# SpinNote 双手机同步版（候选）

1. 在 Supabase 创建项目，在 SQL Editor 执行 supabase-setup.sql。
2. 启用 Email 登录；注册一个账号。
3. 将本文件夹部署到 HTTPS 静态网站，例如 GitHub Pages（不能仅用 file:// 实现稳定的手机同步）。
4. 两台手机打开相同的网址，在页面下方输入相同 Supabase 项目 URL、公开 anon/publishable key 和同一个账号密码并登录。
5. 首次连接自动合并云端数据；打开网页和切回前台时检查更新，前台每约 10 秒轮询。修改后尝试自动上传。
6. 轮盘删除使用删除标记，避免另一台手机把已删除轮盘重新带回来。
7. 定期导出 JSON 备份；不要将 Supabase secret/service_role key 填进网页。

## 注意
- 这是候选版，未在真实 Supabase 服务及两台实体手机上完成端到端验收。
- 手机后台时浏览器可能暂停轮询；再次打开或切回网页会尝试同步。
- 多端同时编辑同一轮盘时按更新时间选择版本；设备时钟偏差可能影响结果，建议不要同时编辑同一个轮盘。
- 删除标记适用于网页内的删除；JSON 旧备份及手动恢复应谨慎操作。
- 数据保存在设备和云端，但不保证永久不丢失；定期导出备份。
- 账号登录令牌保存在标签页 sessionStorage，手机重新开启网页可能需要重新登录。
