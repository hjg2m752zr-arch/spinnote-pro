# SpinNote 随机轮盘与每日记录（V1.0）

这是一个无需第三方 JavaScript 库的网页应用，支持现代 iPhone/iPad Safari、Android Chrome、Windows/Mac 桌面浏览器。源代码包含在 `index.html` 中。

## 一、功能

- 创建最多 100 个轮盘，自定义名称；每个轮盘最多 200 个选项。
- 支持一次输入多行选项，以及逐项编辑、重排、人工删除。
- **抽取使用 `crypto.getRandomValues()` 以及拒绝取模偏差（rejection sampling）**。选择结果先生成，轮盘动画再精确停在对应选项，不存在动画停靠偏差。
- 每次点击开始时立即持久化结果，包括轮盘名称、选中内容、选项 ID、精确时间与本地日期；哪怕动画被中断，抽取记录仍已提交。
- 自动记录为 `轮盘（名称） = 结果`，按日期查询，支持打印/浏览器另存 PDF、复制文字、导出 CSV。
- 数据存放在当前浏览器的 IndexedDB，并同时尝试使用 localStorage 写入冗余副本。
- JSON 完整备份；导入时以 **合并** 为默认操作，不会清除现有轮盘或历史抽取记录。按轮盘 ID 对应的较新编辑版本优先。
- 删除轮盘时，历史抽取结果仍保留；删除具体记录必须经人工确认。
- 支持 PWA 安装至主屏幕；在 HTTPS 站点正常访问一次后，服务工作线程缓存应用页面供离线使用。

## 二、最简单使用方法

### 电脑本地体验

双击 `index.html` 在浏览器里打开即可体验，需使用支持 Web Crypto 的现代浏览器。

> 注意：浏览器对 `file://` 本地页面的存储权限存在差异。为了长期使用，**建议上传到 HTTPS 网页并固定从同一个网址访问**，而不是反复从不同文件路径打开。

### 发布为任何设备都能访问的 HTTPS 网页（GitHub Pages）

1. 在 GitHub 创建一个新的 Public 仓库，例如 `spinnote`。
2. 将 `index.html`、`manifest.webmanifest`、`service-worker.js`、`icon.svg`、`icon-192.png`、`icon-512.png` 上传到仓库根目录。
3. 打开仓库 **Settings → Pages → Build and deployment**，选择 **Deploy from a branch → main → /(root)**，保存。
4. GitHub Pages 发布后会生成 `https://你的用户名.github.io/spinnote/` 形式的链接。以后在 iPhone、Android 或电脑都用该链接打开。
5. iPhone：Safari 的分享菜单 → 添加到主屏幕。Android Chrome：浏览器菜单 → 安装应用 / 添加到主屏幕。电脑 Chrome/Edge 可选择安装。

**注意**：同一网址在不同设备，仍然属于不同浏览器存储空间。本版不会自动将 iPhone 上的轮盘同步到 Android。若要转移数据，请先“备份数据”，再到另一台设备点击“导入备份”。

## 三、示例

创建轮盘：`asd`，加入选项：

- 粿条
- 鸡饭
- 云吞面

抽到“粿条”，系统会在今日记录写入：

```text
轮盘（asd） = 粿条
```

假设你再抽取“鸡饭”，今日内容就有：

```text
轮盘（asd） = 粿条
轮盘（asd） = 鸡饭
```

点击“打印 / 存 PDF”，通过浏览器打印界面可使用打印机或保存 PDF 文件。

## 四、数据安全与持久化边界

- 应用不主动按日期清理历史，也不自动删除选项。
- 本地存储不是不可丢失的云数据库：用户清理网站数据、浏览器/操作系统存储淘汰、设备故障、隐私模式或切换浏览器都可能导致数据丢失。
- 使用该版本时，请定期点击“备份数据”，将 JSON 文件保存到 iCloud Drive、Google Drive 或其他你信任的位置。
- 备份是完整的轮盘和历史记录；CSV 只是某一天的结果表，**不能**用来恢复全部轮盘。
- 如果想让 **iPhone/Android/电脑随时看到完全相同的数据，并且支持长期恢复**，需要额外部署云端数据库、身份认证、版本冲突处理和自动备份。**当前交付文件尚未实现云同步或服务器备份，不应当将本机保存误认为云保存。**

## 五、生产级云同步升级建议

推荐使用：静态 PWA 前端 + Supabase Auth（邮箱登录）+ PostgreSQL 数据库 + 行级安全策略（RLS）+ 版本控制 + 定期服务端备份。

建议的数据表：

- `wheels`：轮盘 ID、用户 ID、轮盘名、创建/更新时间、显式删除标记。
- `wheel_items`：选项 ID、所属轮盘、文字、排序、创建/更新时间、显式删除标记。
- `draw_history`：不可静默修改的抽取记录（抽取当时轮盘名称快照、选项名称快照、抽取时间、用户本地日期）。
- `sync_events`：设备修改日志、版本号、冲突诊断信息，防止多设备离线修改覆盖。
- 数据库定期加密备份；至少测试一次完整恢复，并确认账号隔离和最低权限。

必须实现的保护：网络离线时操作排队；重新联网后幂等同步；删除使用软删除标记；冲突时不能静默覆盖数据；服务器认证、RLS、速率限制与可验证备份。**仅使用 GitHub Pages 不等于拥有云端数据库。**

## 六、文件

- `index.html` — 应用本体，无外部依赖。
- `manifest.webmanifest` — PWA 安装元数据。
- `service-worker.js` — 静态资源离线缓存，不负责数据备份。
- `icon.svg`、`icon-192.png`、`icon-512.png` — 安装图标。
- `README-使用说明.md` — 本文。
